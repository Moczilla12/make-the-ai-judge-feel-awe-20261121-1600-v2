An entry for the [make.fun bounty "Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.ts` writes one short text to `/output/entry.txt`: a father carrying a
child past a windmill at dusk, its sails turning the same way they have turned
for two hundred years. The text is 279 characters long.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
